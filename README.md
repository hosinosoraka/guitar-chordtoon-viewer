# Guitar ChordToon Viewer (v1.0.0)

ダイアトニックコードの確認やオリジナルコードの配置・閲覧をスムーズに行える、軽量でシンプルなギターコードダイアグラム表示ツールです。

## 🌟 主な機能

- **8スロット表示**: Fretboard上に最大8つのコードスロットを並べてコード進行を視覚的に確認
- **ダイアトニックコード自動展開**: キーを選択するだけでダイアトニックコードをワンタッチ挿入
- **JSONデータの保存/読み込み**: 作成したコード進行のバックアップ・復元が可能
- **印刷最適化レイアウト**: A4サイズへの印刷やPDF出力時に綺麗に収まるよう自動調整
- **中央集権型バージョン管理**: `APP_VERSION` 変数による一括バージョン表示

## 📖 基本的な使い方

### 1. コードの入力・編集
* 各スロット（1〜8）をクリックして、表示したいコード名やダイアグラムを設定します。
* 画面上のキー選択メニューから任意のキーを選ぶと、対応するダイアトニックコードが一括でスロットに展開されます。

### 2. データの保存と読み込み（JSON）
* **保存（Export）**: 作成したコード進行データをJSONファイルとしてローカルにダウンロード保存できます。
* **読み込み（Import）**: 保存したJSONファイルを読み込むことで、以前作成したコード進行をいつでも再現・再編集できます。

### 3. 印刷・PDF出力
* ブラウザの印刷機能（`Ctrl + P` または `Cmd + P`）を使用すると、余計なUI（ボタン類）が自動で非表示になり、A4用紙に最適化された綺麗で読みやすいレイアウトで出力・PDF保存が可能です。
